# Flag assets

The real-country PNG flags in this folder were downloaded from FlagCDN on 2026-09-24 using ISO 3166-1 alpha-2 codes. FlagCDN documents that its icons are sourced from `flag-icons` under the MIT License. The Global icon is an original neutral SVG created for this project and is not a national flag.

Source: https://flagcdn.io/docs/
